# Currículum web — Jose Antonio Vilar

Página personal de una sola página publicada con GitHub Pages.

- Web: https://josevilar-qbioai.github.io
- Repositorio: https://github.com/josevilar-qbioai/josevilar-qbioai.github.io

## Estructura

- `index.html` — la página completa (HTML, CSS y JS en un solo fichero).

## Cómo actualizarla

1. Edita `index.html` y revisa el resultado abriéndolo en el navegador.
2. Cambia la fecha de «Actualizado el …» en la cabecera.
3. Guarda los cambios:

   ```bash
   git add index.html
   git commit -m "Actualiza el currículum"
   git push
   ```

GitHub Pages publica los cambios de la rama `main` en uno o dos minutos.
